## Project Title
Personal Expense Tracker

## 1. Problem Statement
Managing daily expenses can be difficult. Users may lose track of their spending and find it hard to know where their money is being spent. This project provides a simple Python-based system to record and analyse expenses.

## 2. Scope
The project allows users to:
- Add and view expenses.
- Calculate total spending.
- Search expenses by category.
- Find the highest and lowest expenses.
- Set a budget and check the remaining balance.
- Validate basic user inputs.

## 3. Target Users
- Students
- Individuals who want to track daily expenses

## 4. High-Level Features
- Expense Management
- Budget Management
- Input Validation

## 5. Technologies Used
- Python
- Visual Studio Code
- GitHub

## 6. Project Modules
- `main.py` – Main menu and program control
- `expense_manager.py` – Add and view expenses
- `analysis.py` – Expense calculations and analysis
- `budget_manager.py` – Budget calculations
- `validation.py` – Input validation
